# Almoxarifado SEASIC

Painel estático de consulta da Base Mestre do Almoxarifado da SEASIC.

**Página pública:** https://luccamachadoo.github.io/radar-seasic-pages/almoxarifado/

## Arquivos

- `index.html`: interface do painel.
- `support.js`: runtime da interface.
- `seasic-data.js`: base consolidada exibida pelo painel.

## Limitações atuais

- Entradas, saídas e configurações são funcionalidades de protótipo e não persistem dados.
- Não há autenticação.
- A base publicada pode ser baixada por qualquer visitante da página.
